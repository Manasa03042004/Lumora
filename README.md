# ✨ Lumora

> A wellness and productivity application designed to help users organize their daily lives, build better routines, and maintain a balanced lifestyle.

## 🌟 About the Project

Lumora is a wellness and productivity application that brings together daily organization and personal well-being in one platform.

The project is designed to provide users with a simple and user-friendly space to manage tasks, maintain routines, track personal goals, and focus on a more balanced and productive lifestyle.

## 🚀 Features

- 📝 Task and daily activity management
- 📅 Routine and schedule organization
- 🎯 Goal tracking
- 🌿 Wellness-focused features
- 📊 Progress tracking and insights
- 🔐 User-friendly and responsive interface

## 🛠️ Tech Stack

**Backend**

**Other Technologies**

## 🎯 Project Objective

The objective of Lumora is to create a single platform that combines productivity and wellness. Instead of treating task management and personal well-being as separate areas, Lumora aims to provide a more balanced approach to managing everyday life.
